Udacity *Identify Customer Segments* project: unsupervised learning (PCA + clustering) on Arvato demographics to find core customer segments for a mail-order company.

Setup with [uv](https://docs.astral.sh/uv/): `uv venv && source venv/bin/activate && uv pip install -r requirements.txt`

Then start JupyterLab with: `jupyter lab` and open `Identify_Customer_Segments.ipynb`.

The Arvato datasets are not included (licensing). Place the CSVs in `data/` locally before running.
